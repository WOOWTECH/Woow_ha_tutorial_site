Chapter 6

Dashboards

Put the lights, covers, and climate controls your household uses most where everyone can find them. A clear dashboard should work without instructions.

Why layout yourself

The HA default will automatically generate an "overview" dashboard that includes all devices - this is good for "understanding what is in your home", but it is too explosive for "daily operations".

What you want is a "open it in the morning, do everything in 3 clicks" screen. To achieve this goal, two things must be done:

  • delete Cards that are rarely used.
  • row Commonly used ones go to the top.

Review the default dashboard

Version differences: Starting from 2026.2, the default dashboard you see when opening a new installation has been replaced by a new one. Home Dashboard, the name on the sidebar is also "Overview". The previous automatic overview of "one card in one area and all the entities stuffed in" has become the old version of the template. You have to select it in "Settings → Dashboard → New Dashboard" Overview (legacy) Only then can it be born. The layout principles of the two are the same, so just follow them below.

The first page you see after logging in is the default dashboard. It will automatically:

  • One card per area.
  • All entities in the area are stuffed inside.
  • The order is sorted internally by HA, there is no structure.

Create your own home page

Suggestion: Create a new dashboard first, do not change the default "Overview". HA official document recommends: The default Overview is automatically generated, and if changed, it will be overwritten by the next automatic scan; create a new "My Home" dashboard and change it however you like.

  1. Edit button (pencil icon) in the upper right corner → "Edit Dashboard"

    Enter editing mode, and a brush icon will appear in the upper right corner of each card. (The old version is the three-click menu in the upper right corner → "Edit Dashboard".)

  2. Delete unnecessary area cards

    Click the card's brush → Trash → Confirm deletion.
    The "card" was deleted, not the "device" - the device is still there, but the card is not displayed.

  3. Add the "Commonly Used Devices" card

    "+ Add Card" in the lower right corner → Select the "Entity" or "Button" card → Select the entity you want (such as the main light in the living room) → Save.

  4. Recommended "Home" Card Set

    • weather (Weather card) - Determine whether to bring an umbrella and turn on dehumidification today.
    • "Who's home?" (Person Card) - See who is and who is not at a glance.
    • Common scene buttons (Button card) - For example, "go home", "leave home", and "sleep".
    • All areas are fully open / fully closed (The Button card performs the action Action, which was called "Call Service" in the old version; select it in the card's action settings. perform-action)—Switch all lights on the first floor with one click.

  5. Reorder cards

    Hold down the card and drag it to the desired location. Put the most commonly used ones at the top.

  6. Click "Done" in the upper right corner to exit editing mode.

    If you don’t press Finish, the settings will not be saved!

Verify: You can see the name of the new dashboard from the left menu; click on it to see the card you just added; rotate the browser and put it horizontally and it should be arranged neatly (the Sections view will be automatically responsive).

Multiple views and pages

A dashboard can have multiple pages (Views):

  • Home page: Commonly used operations.
  • Each floor: The first and second floors are divided into pages, each page is detailed.
  • energy: Electricity, solar energy.
  • security: Monitors, door locks, sensors.

The "+" sign in the upper right corner of the editing mode adds a new page. Each tab can independently set "who can see it".

Which of the four view types should you choose?

Each tab (view) can independently select the layout:

  • Sections (default after 2024.03): Drag the partition and the phone/desktop computer will automatically layout. Newbies choose this directly.
  • Masonry (brick wall): Old version default, cards are automatically stacked. You can keep the old version if you are used to it.
  • Panel (single card): Place only one card in the entire view (e.g. map, energy overview). Exclusive dashboard suitable for large screens.
  • Sidebar: Resident card on the right + replaceable card on the left. Suitable for tablets.
Suggestions: If you're not sure, choose Sections. It's much easier to use than the old version. The old view can be "added to the Sections version" without deleting the original one, and can be switched at any time.

3 layout tips

Tip 1: Group with Sections. HA's current main recommended view type is Sections (becomes the default after 2024.03), which can separate "lighting", "air conditioning" and "curtains" into blocks, which is clearer than a long one.
Tip 2: Arrange the mobile version separately. There is a "View → Desktop/Mobile" preview in the upper right corner of the editing mode, so you can see what the mobile version looks like. The mobile version recommends one column and 3-5 fewer cards.
Tip 3: Make good use of "conditional display". The card has a "Display Condition (Visibility)" setting, which allows you to "display the dehumidifier card only when it rains" and "guest accounts cannot see the master bedroom light."
Advanced: Let family members see different cards. use Conditional card Enclose the content you don’t want an account to see, select "user" in the conditions and check visible accounts. With the guest account in Chapter 5, you can achieve the effect of "visitors can see the lights but not the monitor".

FAQ

Is it possible to save accidentally deleting the wrong card?
If you have not left the editing mode, click "Restore" in the upper right corner; if you leave, you must rebuild. Therefore, it is recommended to copy YAML to Notepad for backup before major changes.
Can I make a copy of the entire dashboard for my child to use?
Yes. "Settings → Dashboard → New Dashboard" → Copy from template → Assign to a user. In this way, parents and children each have their own home page.
Is it possible to install more beautiful cards on HACS?
Yes, for example, mushroom-cards and button-cards are popular. But first use the built-in cards to walk through it, and then install it after you understand the concept, so you will be less likely to get lost.

Common problems

Can't drag the card or click edit?
Click the edit button in the upper right corner (pencil icon, the old version was a three-click menu) and select "Edit Dashboard" to enter the edit mode. If you don't see that button, it usually means you don't own the dashboard (for example, logged in with a guest account).
How to restore the default Overview if it is changed?
"Settings → Dashboard → Overview → Three dots in the upper right corner → Regenerate". If even the restore fails, choose a pre-restore backup from the backup in Chapter 9 and restore it.
Is the dashboard you see when you open the Companion App on your phone different from that on your computer?
Companion App can specify the "default dashboard when opening" in the App settings, which is set separately from the web browser.
