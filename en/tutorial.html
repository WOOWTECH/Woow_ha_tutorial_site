Home Assistant Onboarding Guide

From scratch to functional

Set the newly installed Home Assistant from a blank state all the way to the point where you can turn on lights with two clicks on the wall, receive notifications on your phone, and then go down to communication protocols, energy monitoring, voice assistants, and field-level network architecture. 22 chapters + 3 appendices, 10 minutes each. Sales brochures, AI prompt lexicon and skill manuals are in Resource Hub.

Foundations: from zero to working

01

Log in to Home Assistant

Learn the login page, “Stay logged in,” and when to use the web interface or Companion App.

 02

System settings

Set the correct time zone, language, units, and location so that later automations run as expected.

 03

Floors and areas

Map your home’s floors and rooms so dashboards, voice control, and automations understand where devices are.

 04

Naming and labels

Turn an opaque entity ID into a clear name, then use labels to group related devices and automations.

 05

User management

Create accounts for household members, tenants, and guests, with appropriate permissions for each person.

 06

Dashboards

Put frequently used lights, covers, and climate controls where everyone can find them.

 07

Notifications

Install the Companion App, connect a phone, and send your first push notification.

 08

Your first automation

Use the trigger-condition-action model to turn on a light at sunset without falling into the device_id trap.

 09

Backups

Configure automatic backups in three minutes so you can experiment and recover with confidence.

 10

Scripts

Package repeated actions into a reusable, parameterized script that dashboards, automations, and voice control can call.

 11

Device settings

Read the device page, update firmware, manage entities, download diagnostics, and use Repairs.

 12

Domain reference

A practical reference to common domains, their actions, dashboard cards, and frequent pitfalls.

Extensions: connect more devices

13

Themes and appearance

Choose light or dark mode, install a community theme, and tailor Home Assistant’s appearance for each user.

 14

Integrations

Connect weather, music, location, calendar, and other external services to Home Assistant.

 15

Communication protocols

Compare Wi-Fi, Zigbee, Z-Wave, Matter, Thread, Bluetooth, KNX, Modbus, and MQTT before buying devices.

 16

To-do lists and calendars

Move household reminders into shared to-do lists and calendars that can trigger automations.

Data, energy, and AI

17

Energy dashboard and ESG practices

Turn energy readings into useful charts, cost tracking, baselines, and defensible reports.

 18

History, Recorder, and data export

Learn where Home Assistant stores history, how long it lasts, how to export it, and how to keep the database healthy.

 19

Voice assistants and LLM integration

Build an Assist pipeline, then compare local and cloud speech and LLM options with their privacy and cost trade-offs.

Advanced architecture and applications

20

Add-ons and Docker architecture

Understand how Supervisor-managed Docker containers power add-ons and how to troubleshoot them.

 21

Networking and remote access

Set a stable local address and compare four secure ways to reach Home Assistant away from home.

 22

Life logging and custom dashboards

Track habits, household spending, maintenance, and notes, then turn those records into useful dashboards.

Appendices

A

Ecosystem: HACS, add-ons, and remote access

Compare official add-ons, the HACS community store, and four remote-access options.

 B

Scenes, helpers, and groups

Use scenes, ten helper types, and groups as reusable building blocks for automations.

 C

Before installation: hardware and HAOS

No host yet? Choose hardware and storage, install HAOS, and complete first-time setup.
