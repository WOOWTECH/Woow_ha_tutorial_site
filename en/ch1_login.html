Chapter 1

Sign in to Home Assistant

First make sure you can enter the the dashboard reliably. This is the prerequisite for all subsequent chapters. This chapter teaches you to recognize the login page, remember the login status, and understand the difference between "web interface" and "Companion App".

Why should you learn this?

Home Assistant (hereinafter referred to as HA) is a "locally controlled" smart home hub: all device status, automation, and room data are stored on the small host in your home and will not go through the cloud.

Because it is your own server, the login method is different from ordinary Internet services:

  • There is no "forgot password" - the password is known only to the host.
  • It is possible to enter through the local network IP, or through the domain name (Nabu Casa/self-hosted DDNS).
  • The login experience on mobile phones and computers is different - it is recommended to install Companion App on mobile phones and use a browser on computers.

Two roles that are often confused: Owner vs Administrator: The first account created during installation is the "Owner", which has the greatest authority andOnce the password is forgotten, it cannot be retrieved(HA official document clearly states this). The administrator account you create in ch5 later has close permissions, but is not the owner. There can only be one owner.

Find your HA URL

Your URL will usually be one of three:

  • LAN IP: http://homeassistant.local:8123 or http://192.168.x.x:8123.
  • Nabu Casa Remote: https://xxxxx.ui.nabu.casa(Paid subscription).
  • Self-hosted domain: For example https://ha.yourdomain.com(For example, the author uses a self-hosted domain https://woowtech-ha.woowtech.io).
Tip:Add the URL to the browser bookmarks, and "Add bookmarks to desktop" on the phone's home screen, then click to open it.

Login steps

Version differences:The default dashboard you see after logging in will be called "Home" starting from 2026.2; before that, it was called "Overview". The old version of the interface will say "Overview" at the top of the sidebar. Both are in the same location and the following steps apply.

  1. Open login page

    Enter the HA URL in the browser, and you will see a blue and white login card with the Home Assistant logo in the middle.

  2. Enter username and password

    Use the administrator account created when you originally installed HA. If you are a family member/tenant, please ask the administrator for a dedicated account (Chapter 5 will teach you how to create one).

  3. Check "Stay logged in"

    Once checked, this browser will remember you so you don't have to retype your password every time you open it. The official document does not spell out the number of days, but only states that "login credentials that have not been used for more than 90 days will be automatically cleared." So as long as you keep using it, in practice, you will always keep logged in.Do not select this option on a shared computer.

  4. Enter the dashboard

    After successful login, you will jump directly to the "Home" dashboard (the old version was called "Overview"), which displays status cards for each area of your home.

Web vs. Companion App

The two are connected to the same backend, and the data is completely synchronized. The difference lies in the functions:

  • web page: Large screen, suitable for changing settings, writing automation, and viewing historical charts.
  • Companion App(iOS/Android): Can receivepush notification, report mobile phoneBattery/Location/WiFi NameSet trigger conditions for HA and quickly log in through biometrics.
Recommended practices:Use the browser on your computer to change settings, and install the app on your phone for daily control and notifications. Chapter 7 will walk you through installing the app.
Next step: Chapter 5 teaches you how to open a dedicated account for your family, and Chapter 7 teaches you how to receive notifications on your mobile phone.

FAQ

What should I do if I forget my password?
The password is stored on the host and no reset message has been sent.If you can still log in and are the owner, just go to "Settings → Personnel" and select that person to change the password.If you are locked out, HAOS needs to connect the on-screen keyboard to the host itself, and type on the directly connected console. auth reset --interactive Reset (the official document specifically states: You cannot use the SSH terminal in the App or add-on, you must use the screen of the host itself); Docker installation is to run into the container hass --script auth --config /config change_password account new password Restart the container. If you are not an administrator, the fastest way is to ask the administrator to reset it for you from "Users" in Chapter 5.
The login page keeps spinning around and you can’t get to it?
First confirm whether the URL is correct and whether your mobile phone/computer is connected to your home WiFi (the local network IP can only be connected at home). If it is an external network address, check whether the HA host is still open and whether Nabu Casa or DDNS has failed.
Can I use the same account to log in to multiple devices?
Yes, each device is an independent session, and logging out of one will not affect the others.

Troubleshooting failed login

Try the following list one by one:

  1. Is the URL correct?

    First open it with a browser under the same WiFi http://homeassistant.local:8123. This is the HAOS default mDNS URL.

  2. SSL certificate warning?

    If you see an "unsafe" warning when using a local network IP, it is normal (no certificate), just click "Advanced → Continue".

  3. Forgot owner password

    The official statement states that "the owner password cannot be retrieved from within Home Assistant." The correct solution to HAOS is to connect the on-screen keyboard to the host and execute it directly on the console auth reset --interactive(SSH terminal cannot be used); Docker is used to enter the container hass --script auth Change. If both methods fail, the only option left is to rerun the initial settings or restore from backup (will be taught in ch9). This is whyCreate a backup as soon as possible.

  4. Companion App keeps failing to log in

    The login of the App version uses the external network address; if there is no external setting at home, it will fail. ch7 will install the App, and the appendix talks about the remote connection solution.
