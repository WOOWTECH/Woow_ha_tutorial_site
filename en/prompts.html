43 Home Assistant prompts for AI

Connect Home Assistant to Claude, ChatGPT, or Gemini through an HA MCP server such as ha-mcp-woow. These 43 English prompts cover eight practical categories; copy one, then replace example areas and entity IDs with those in your home.

What this handbook covers

Home Assistant’s REST API, WebSocket API and new version MCP server Let the LLM agent call any service, read any entity status, and run any template. match ha-mcp-woow or official MCP Server integration, your AI can:

  • control: call light.turn_on, climate.set_temperature, cover.open_cover Wait for all services
  • Query: Read entity status, attributes, and historical data, and answer "What's the current temperature in the living room?" "How much electricity was used last week?"
  • Edit: Add/modify/delete automation, scripts, scenes, dashboards
  • management: Install/remove add-ons, HACS packages, integration, run backups and upgrades

Every item included in this handbook is Written for AI agent to read Natural language prompts - not short commands for Voice Assistant, but complete demand descriptions that allow AI to actively translate into one or more action calls, confirm back and forth with you, and leave operation records.

How to start using it

  1. Connect HA to MCP server

    Option 1: Official MCP Server integration (HA 2025.7+) → Direct connection to clients such as Claude Desktop/VS Code Copilot. Option two:ha-mcp-woow(Enhanced version from WoowTech, including more complete config/HACS/backup tools, see Chapter 19 with Chapter 20).

  2. Expose entities to LLM

    Settings → Voice Assistants → Expose: Check the areas and entities you want the AI to move. Security advice: Expose only the "harmless" ones (lights, sensors) first, verify that the behavior is correct, and then release the safe ones (door locks, alarms).

  3. Copy the prompts corresponding to the scenario in this handbook

    Replace bracket-like words like "living room", "master bedroom" and "26 degrees" with the actual areas/devices/parameters of your home, and paste them into the dialog box of Claude/ChatGPT/Gemini.

  4. Develop the habit of “reporting first and then taking action”

    For all prompts that will change the settings, keep the words "give me a summary first, and I will confirm and then apply" - important changes should be reviewed before being approved, which is the cheapest insurance.

Tip: Didn't answer the MCP and just want to talk via voice? Use built-in instead Assist conversational agent (Settings → Voice Assistants), the effect is not as good but it can still be used. The prompts in this handbook are probably too long under Assist and will be truncated.

Energy monitoring and power saving analysis

Analyze the living-room air conditioner’s energy-use curve over the past 30 days and correlate it with outdoor temperature. Compare energy use at setpoints of 25 and 26 degrees, then recommend savings based on this household’s usage periods. Respond in English.

Report the current instantaneous total power from sensor.total_power. If it remains above 5000 W for 3 minutes, pause deferrable high-power devices such as the dehumidifier, dishwasher, and dryer for 30 minutes to avoid exceeding the contracted power limit. Respond in English.

Troubleshooting and maintenance

go ha_get_logs/ha_get_automation_traces/ha_get_system_health/ha_manage_backup. These are the most valuable batches when something goes wrong with HA.

The “Turn on the lights at sunset” automation did not trigger this morning. Use ha_get_automation_traces to retrieve its five most recent traces and identify the cause. If a fix is available, summarize it and wait for my confirmation before applying it. Respond in English.

Use ha_get_logs to retrieve entries at log_level=ERROR or higher from the past 24 hours. Group them by integration and entity, identify the groups with the most errors, and recommend the three highest-priority fixes. Respond in English.

Run ha_get_system_health once and check Recorder, Supervisor, and networking for unhealthy states. If you find a problem, follow the repair steps in the official Home Assistant documentation. Respond in English.

List automatic backups from the past 7 days. Confirm that one ran each day and that every file is > 100MB, because a much smaller file may be incomplete. If the newest backup is more than 24 hours old, run a full backup first and then report the result. Respond in English.

Use ha_report_issue to report the current open issues from Repairs. List each issue by severity and explain which can be deferred and which require action. Respond in English.

Cheat sheet for writing prompts for AI

After reading 43 items, the routine actually only has five moves. Writing instructions to an AI agent is different from writing instructions to a human being:

Put it this wayDon't say thatwhy
Use entity_id to say: "Open light.living” or use the friendly name “Turn on the main light in the living room” "Turn on that light" "Turn on that light" The AI agent requires a specific entity_id or an explicit name to call the service.
Specify which service to use: "Use climate.set_temperature Assume 26" "Turn it to 26 degrees" (let the AI guess randomly) Complex control explanation tool, AI will not use the wrong service. Simple instructions can be spoken.
Read first, then write: "Read the existing automation YAML for me first, and then tell me how you want to change it." "Help me change xxx automation" If you change it without reading the original text, it will most likely be bad. This is the iron rule to preserve the existing settings.
Summary first and then apply: "Give me the YAML summary and I will confirm and then enable it" "Help me add an automation" Anyone who knows how to use config should add this sentence, the cheapest insurance.
Use entity_id instead of device_id: "Trigger binary_sensor.front_door” Use device_id UUID If device_id changes the device, the connection will be broken, but entity_id is stable; this is also Chapter 8 iron law.
Safety reminder: Connect HA to LLM = give AI the ability to change your home's settings and trigger entities. When Exposing entities, only the "harmless" ones (lights, sensors) will be placed first, and after a few weeks of verification, the security categories (door locks, alarms, main power switches) will be opened. Actionable prompts retain the phrase "summary first and then apply".

FAQ

What is the difference between MCP server and REST API and Voice Assistant?
Voice Assistant (Assist) uses intent, short commands, and is pre-defined; REST API is an HTTP call service, suitable for writing programs; MCP server is a "tool directory" for LLM agent - AI can dynamically discover which services can be called, which states can be read, and which settings can be modified, without the need to hard-code intentions in advance. The prompts in this handbook are all for MCP/API, and the length and complexity are beyond the capabilities of Assist.
Should I use ha-mcp-woow or official MCP Server integration?
Home Assistant integration (HA 2025.7+) is enough, covering state query + action call;ha-mcp-woow It is an enhanced version of WoowTech, with additional config editing, HACS management, backup tools, log/trace query, etc. (many prompts used in this handbook ha_config_set_*, ha_get_automation_traces, ha_manage_backup That’s what it comes from). If you want a complete experience, choose ha-mcp-woow, I just want to try it safely and choose Home Assistant one.
What should I do if AI often calls the wrong service or gives the wrong entity_id?
Three common reasons: (1) The entity is not exposed to LLM (Settings → Voice Assistants → Expose), (2) The naming is too vague and AI cannot guess it (sensor.abc123 Than sensor.living_temperature Difficult to use), (3) The LLM context is too stuffed, and important entities are truncated. Correction: Name first (Chapter 4), then expose, and finally only expose relevant areas.
Will it cost a lot of tokens/expensive?
Daily control (turning on lights, checking temperature, single automation) costs almost no money; energy analysis, log capture of the entire domain for 7 days, and large-scale reconstruction of automation will cost tokens. Save money: only expose relevant entities, use cheap models (Claude Haiku, GPT-4o mini) for large analysis, and switch to strong models for complex planning.
Can it be triggered automatically instead of manually posting prompts every time?
Yes. Wrap the prompts in this handbook into skills (see Skill Manual), or made into HA script bring service: conversation.process To LLM. Advanced approach: Use HA automation to trigger LLM analysis and perform corresponding actions on specific events (water leakage, low battery) - but pay special attention to safety at this time, and do not allow the AI ​​to do unrecoverable operations.
Can prompts be used directly with family members?
Yes. Download this page as a single HTML file and send it to the family group. Everyone can choose their own scene and copy and paste it directly. With the "Daily Voice Conversation" section, even non-technical family members can get started.
