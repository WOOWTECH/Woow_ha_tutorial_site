Chapter 4

Naming and labeling

put switch.0x00abc123_2 Change it to "living room main light". After the modification, the voice assistant, dashboard, and automation can all be understood. Then learn to "tag" to group similar devices, and then management time will be saved 10 times.

Why rename

The name of the newly paired device is the technical code given by the manufacturer, for example:

  • light.aqara_light_group_2
  • switch.0x00158d000abcd1234
  • sensor.motion_sensor_ambient_temperature

There are two problems with these names:

  1. The voice assistant can’t read — You don’t say to Google “please open aqara_light_group_2”.
  2. My family can’t understand — There is a pile of scriptures on the dashboard that no one dares to press.

Solution: Change everything to "names you'll blurt out."

Let’s first distinguish the three names

HA has three levels of names, which are easy to confuse:

  • Device name: The name of the entire device, such as "Living Room Ceiling Lamp".
  • Entity ID: Internal ID used by the program, for example light.living_room_ceiling.Use this when writing automation.
  • Friendly name: The name displayed in the user interface, such as "Main Light".Use this for display and voice.
Good habits:Write the full name of the device ("Living Room Ceiling Lamp"), and write the short version of the friendly name ("Main Light") - because the friendly name already has the area in front of it, it just becomes "Living Room Main Light".

Rename step

Version differences:The "Settings → Tools" that will be used below was an independent "Developer Tools" on the sidebar before 2026.2; it was included in "Settings" in 2026.2, and the name was simplified from "Developer Tools" to "Tools" in 2026.8. The page names (status, template...) inside have not changed. For older versions, please go to the "Developer Tools" in the sidebar to find the same thing.

  1. Go to "Settings → Devices and Services → Entity"

    When you see a long list of all entities, you can use the search box above to quickly find a device.

  2. Click an entity → Gear (Settings)

    Open the entity details and use the gear in the upper right corner to enter the settings page.

  3. Change the "Name" field

    What is changed here isfriendly name. The entity ID will not be changed because the ID is an automated key and will be broken if it is changed.

  4. Do you want to change the entity ID together?

    It is recommended to change.If this is a newly installed device and has not been referenced by any automation, just change the ID to a meaningful alphanumeric value, for example light.living_room_main. It will be easy to look at the code later.

    Warning:For entities that have been referenced by automation, scripts, and dashboards, before changing the ID, search in "Settings → Tools → States (States)" to see if it has been used.
Verify: After the change, the new name should be found in "Settings → Tools → Status"; the old entity_id should disappear from the list.warning: If this entity is used by automation, changing the entity_id will break the automation - Chapter 8 will explain why you need to think of a good name from the beginning.

Classify with labels

The area answers "Where is this lamp?" and the label answers "What type of lamp is this?" For example:

  • Lamps and equipment are all attached illumination Tag — and then “turn off all lighting” with just one click.
  • USB powered devices are attached Uninterrupted power supply Tags — Don’t worry when the power goes out.
  • All equipment that tenants will use is posted Tenant control Tags — filter this when building the dashboard.

  1. Create a label: Settings → Labels → New

  2. Label entities

    Check multiple boxes on the left side of the entity list → "Add tags" at the top - paste them all at once.

  3. How to use it later

    Labels can be attached to more things than you think: Areas, equipment, entities, automation, scripts, scenes, and helpers can all be posted; one thing can have multiple Labels (unlike areas that can only belong to one). This is the most flexible classification tool in HA.

    Automated trigger conditions, dashboard filtering, and script references can all use "labels" to replace individual column entities. Even if the entity is changed, the label remains unchanged, making maintenance very easy.

FAQ

If the entity ID is changed, will all the old automation be rewritten?
HA has the function of "synchronously updating automation references when renaming", but it only covers the automation of UI creation. YAML handwritten and Node-RED need to be searched and replaced by yourself.
What is the difference between "label" and "area"?
The area is "location" (where), and the label is "property" (what type / who can control / what use). A device can only belong to one zone, but can have multiple tags.
Can friendly names be repeated?
Yes. Different areas with the same name will not conflict (HA will be displayed with the area prefix). However, the voice assistant will not be able to tell the difference when giving instructions, so it is recommended to avoid it.

Common stuck levels

After changing the entity_id, a certain automation does not move?
Because the automation refers to the old entity_id. Go to "Settings → Automation" to check one by one, or use "Settings → Tools (the old sidebar is called "Developer Tools") → Templates" to search for the old name. This is why Chapter 8 will teach "Always use entity_id instead of device_id" - if you change the entity_id, at least you will find out that it is broken immediately. If the device_id is changed, it will be harder to find out.
What is the difference between Friendly name and entity_id?
friendly name is the Chinese name displayed on the UI (for example: the main light in the living room), which can be changed without breaking anything; entity_id is the system identification code (for example:light.living_room_main), changes will affect all automations, dashboards, and scripts that reference it.Normally just change the friendly name.
Can I change the name in batches?
HA itself does not have a batch rename UI. Can be edited directly .storage/core.entity_registry(Not recommended, easy to break) Or use "Bulk Rename" on HACS to customize the card. Safe approach: Modify new equipment once and then move on to the next one.
